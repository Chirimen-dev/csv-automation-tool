# CSV自動整理・統合ツール

複数のCSVファイルを読み込み、データの整理・統合を自動化するPythonツールです。手作業によるCSV整理の手間を減らすことを目的に作成しました。

## 主な機能

* 複数のCSVファイルをまとめて統合
* 列名とセル内の文字列の前後にある空白を削除
* 空欄・欠損セルの数を集計
* 重複する行を検出して削除
* 必須列や列構成の不一致を検出
* UTF-8系とCP932のCSVファイルを読み込み
* 処理結果をレポートとして出力

## 使用技術

* Python
* pandas
* Git / GitHub

## 使い方

1. 統合したいCSVファイルを `input/` に入れます。

2. プロジェクトのディレクトリで仮想環境を有効にします。

   ```bash
   source .venv/bin/activate
   ```

3. ツールを実行します。

   ```bash
   python csv_tool.py
   ```

## 出力ファイル

| ファイル                | 内容                |
| ------------------- | ----------------- |
| `output/merged.csv` | 整理・統合後のCSV        |
| `output/report.txt` | 処理件数や欠損セル数などのレポート |

## 必須列

* 氏名
* メールアドレス
* 電話番号

## エラー処理

必須列の不足やCSV間の列構成の不一致などを検出した場合、問題のあるファイルや列を表示して処理を中止します。

## テスト

サンプルCSVを使用し、通常の統合処理に加えて、列の順序違い、必須列不足、文字コードの違い、空欄、重複行などのケースを確認しました。
