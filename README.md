# CSV自動整理・統合ツール

複数のCSVファイルを読み込み、データの整理・統合を自動化するPythonツールです。手作業によるCSV整理の手間を減らすことを目的に作成しました。

## 主な機能

* 複数のCSVファイルをまとめて統合
* 列名とセル内の文字列の前後にある空白を削除
* 空欄・欠損セルの数を集計
* 重複する行を検出して削除
* 必須列や列構成の不一致を検出
* UTF-8系とCP932のCSVファイルを読み込み
* 処理結果をレポートとして出力

## 使用技術

* Python
* pandas
* Git / GitHub

## 使い方

1. 統合したいCSVファイルを `input/` に入れます。

2. プロジェクトのディレクトリで仮想環境を有効にします。

   ```bash
   source .venv/bin/activate
   ```

3. ツールを実行します。

   ```bash
   python csv_tool.py
   ```

## 出力ファイル

| ファイル                | 内容                |
| ------------------- | ----------------- |
| `output/merged.csv` | 整理・統合後のCSV        |
| `output/report.txt` | 処理件数や欠損セル数などのレポート |

## 必須列

* 氏名
* メールアドレス
* 電話番号

## エラー処理

必須列の不足やCSV間の列構成の不一致などを検出した場合、問題のあるファイルや列を表示して処理を中止します。

## テスト

サンプルCSVを使用し、通常の統合処理に加えて、列の順序違い、必須列不足、文字コードの違い、空欄、重複行などのケースを確認しました。

## 実行結果の例

サンプルCSV 3ファイルを処理した際の結果です。

```text
対象のCSVファイル: 3件
処理前の総行数: 9
重複削除数: 2
欠損セル数: 1
処理後の総行数: 7
```

処理結果は `output/merged.csv` に、処理件数などのレポートは `output/report.txt` に出力されます。

# Excel売上データ自動集計・レポート作成ツール

複数のExcelファイルから売上データを読み込み、月別・商品別の集計とグラフ付きレポートの作成を自動化するPythonツールです。手作業による集計時間や入力ミスの削減を目的に作成しました。

## 主な機能

* 複数のExcelファイル（`.xlsx`）をまとめて読み込み
* 列の順番が異なるファイルにも対応
* 日付・数量・単価の不正なデータを検出して除外
* 数量 × 単価による売上金額の計算
* 月別・商品別の売上集計
* 売上グラフの作成とExcelブックへの挿入
* 処理件数やエラー内容をテキストレポートに出力

## 使用技術

* Python 3.12
* pandas
* openpyxl
* matplotlib

## 使い方

1. 集計したいExcelファイルを `excel-report-tool/input/` に入れます。

2. リポジトリのルートディレクトリで仮想環境を有効にします。

   ```bash
   source .venv/bin/activate
   ```

3. ツールを実行します。

   ```bash
   cd excel-report-tool
   python sales_report.py
   ```

## 出力ファイル

| ファイル                        | 内容                              |
| --------------------------- | ------------------------------- |
| `output/sales_report.xlsx`  | 全売上データ、月別・商品別集計、グラフを含むExcelレポート |
| `output/process_report.txt` | 読み込んだファイル数、処理件数、除外データ、エラー内容など   |
| `output/monthly_sales.png`  | 月別売上グラフ                         |
| `output/product_sales.png`  | 商品別売上グラフ                        |

## サンプルデータ・実行結果

`excel-report-tool/input/` にサンプルのExcelファイルを用意しています。実行後のレポートとグラフは `excel-report-tool/output/` に出力されます。
