# Excel売上データ自動集計・レポート作成ツール 仕様書

## 1. 目的
複数のExcelファイルに記録された売上データを自動で集計し、月別・商品別の売上レポートを作成する。
手作業による集計時間や入力ミスを減らすことを目的とする。

## 2. 使用技術
- Python 3.12
- pandas
- openpyxl
- Excelファイル（.xlsx）

## 3. 入力データ
- input/ フォルダ内のすべての .xlsx ファイルを対象とする。
- 各ファイルには、以下の列が含まれること。
  - 日付
  - 商品名
  - 数量
  - 単価
- 売上金額は「数量 × 単価」で計算する。
- ファイルごとに列の順番が異なっていても、列名で判定する。
- 一時ファイルなど、ファイル名が「~$」で始まるものは無視する。

## 4. 処理内容
1. input/ フォルダ内のExcelファイルを読み込む。
2. 列名と商品名の前後にある余分な空白を削除する。
3. 必須列が不足しているファイルは、ファイル名と不足列を報告して処理対象から除外する。
4. 日付を日付型に変換する。
5. 数量と単価を数値に変換する。
6. 日付・数量・単価が不正な行は、ファイル名と行番号を記録して除外する。
7. 売上金額（数量 × 単価）を計算する。
8. 読み込んだ有効データを結合する。
9. 月別売上と商品別売上を集計する。
10. 月別売上・商品別売上のグラフを作成する。
11. 集計結果と処理レポートを出力する。

## 5. 出力ファイル
- output/sales_report.xlsx
  - 全売上データ
  - 月別売上集計
  - 商品別売上集計
  - 月別売上グラフ
  - 商品別売上グラフ
- output/process_report.txt
  - 読み込んだファイル数
  - 正常に処理したファイル数
  - 除外したファイル数
  - 読み込んだ行数
  - 有効データ行数
  - 除外した行数
  - ファイルごとのエラー内容

## 6. エラー処理
- input/ フォルダが存在しない場合は、理由を表示して終了する。
- 対象のExcelファイルがない場合は、その旨を表示して終了する。
- 必須列が不足するファイルは除外し、エラー内容を記録する。
- すべてのファイルに有効なデータがない場合は、出力ファイルを作成せず終了する。
- 読み込みに失敗したファイルがあっても、ほかのファイルの処理は続ける。
- output/ フォルダが存在しない場合は自動作成する。

## 7. 実行方法
仮想環境を有効化した状態で、次のコマンドを実行する。

python sales_report.py

## 8. テスト項目
- 正常なExcelファイルを複数読み込める。
- 列の順番が異なるファイルを正しく処理できる。
- 必須列が不足するファイルを除外できる。
- 不正な日付や数量・単価を含む行を除外できる。
- 月別・商品別の売上集計が正しい。
- グラフ付きExcelレポートを出力できる。
- 入力ファイルが存在しない場合に適切なメッセージを表示できる。
- 一部ファイルの読み込みに失敗しても、ほかのファイルを処理できる。
